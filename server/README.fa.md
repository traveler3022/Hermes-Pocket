# هرمس روی سرور خودت

[English](README.md)

اپ هرمس می‌تواند به Hermes Agent روی سرور لینوکسی خودت وصل شود. این اتصال فقط از شبکهٔ خصوصی Tailscale خودت می‌رود:

- هرمس روی سرور فقط روی `127.0.0.1` می‌ماند و هیچ پورتی روی اینترنت باز نمی‌شود.
- فقط دستگاه‌هایی که با حساب Tailscale خودت وارد شده‌اند، با اتصال رمزنگاری‌شده، به آن می‌رسند.
- Tailscale داخل خود اپ است و اپ Tailscale روی گوشی لازم نیست.

## پیش‌نیازها

- سرور لینوکس با systemd (مثل Ubuntu یا Debian) که [Hermes Agent](https://github.com/NousResearch/hermes-agent) رویش نصب است.
- یک حساب رایگان [Tailscale](https://tailscale.com).

## ۱. راه‌اندازی سرور (یک دستور)

روی سرور، با همان کاربری که هرمس برایش نصب شده، این را بزن:

```sh
curl -fsSL https://raw.githubusercontent.com/traveler3022/Hermes-android-termux-/main/server/setup.sh | sudo bash
```

اگر با root وارد شده‌ای، `sudo` را نزن. این اسکریپت ([setup.sh](setup.sh)):

1. اگر Tailscale نصب نباشد نصبش می‌کند و یک لینک ورود نشان می‌دهد. بازش کن و با همان حسابی وارد شو که در اپ استفاده می‌کنی.
2. اگر Tailscale لینکی برای روشن کردن HTTPS نشان داد، بازش کن و HTTPS را روشن کن. اسکریپت منتظر می‌ماند.
3. برای داشبورد هرمس نام کاربری، رمز و کلید امضا می‌سازد و در `~/.hermes-remote.env` نگه می‌دارد (فقط همان کاربر می‌تواند بخواندش).
4. داشبورد را به‌صورت سرویس `hermes-dashboard` روی `127.0.0.1` روشن می‌کند، تا بعد از هر ری‌استارت خودش بالا بیاید.
5. با `tailscale serve` آن را فقط داخل شبکهٔ Tailscale خودت در دسترس می‌گذارد.

آخر کار نام کاربری و رمز را نشان می‌دهد. اجرای دوباره مشکلی ندارد و رمز عوض نمی‌شود.

## ۲. وصل کردن اپ

در اپ برو به **تنظیمات ← سرور**:

1. «ورود به Tailscale» را بزن و با همان حساب سرور وارد شو.
2. سرورت را در لیست دستگاه‌ها انتخاب کن.
3. نام کاربری و رمز مرحلهٔ ۱ را بزن و «ورود» را بزن.

اپ رمز را رمزگذاری‌شده روی گوشی نگه می‌دارد و خودش دوباره وارد می‌شود؛ پس فقط یک بار تایپش می‌کنی.

## عوض کردن رمز

```sh
curl -fsSL https://raw.githubusercontent.com/traveler3022/Hermes-android-termux-/main/server/setup.sh | sudo bash -s -- --new-password
```

همهٔ دستگاه‌ها خارج می‌شوند و یک بار رمز جدید را می‌خواهند.

گزینه‌های دیگر: `--username NAME` (نام کاربری برای ورود جدید، پیش‌فرض `admin`)، `--user NAME` (کاربر لینوکسی که هرمس مال اوست)، `--port N` (پیش‌فرض `9119`).

## بررسی، خاموش کردن، حذف

```sh
systemctl status hermes-dashboard          # روشن است؟
sudo tailscale serve status                # باید «tailnet only» بنویسد
sudo systemctl disable --now hermes-dashboard
sudo tailscale serve --https=443 off
```

## قانون‌های امنیتی

- هرگز برای هرمس `tailscale funnel` نزن: Funnel آن را روی اینترنت می‌برد. اگر اسکریپت Funnel را روشن ببیند، داشبورد را خاموش می‌کند.
- هرگز داشبورد را با `--host 0.0.0.0` روشن نکن و پشت nginx یا هر پراکسی عمومی دیگری نگذار. داشبورد می‌تواند هر دستوری را روی سرور اجرا کند.
- پیشنهاد: در کنسول Tailscale گزینهٔ **Device approval** را روشن کن تا هر دستگاه جدید تأیید تو را لازم داشته باشد.

## رفع مشکل

- **«Hostname … not verified»** با یک گواهی دیگر: Tailscale Serve خاموش است و اتصال به وب‌سرور دیگری روی همان سرور خورده است. دستور راه‌اندازی را دوباره بزن.
- **«Can't find ….ts.net»**: اپ با حساب Tailscale دیگری غیر از حساب سرور وارد شده است.
- اتصال اول ممکن است تا یک دقیقه طول بکشد، چون Tailscale دارد گواهی HTTPS را می‌گیرد.
- تست با curl **از روی خود سرور** هیچ‌وقت از Tailscale Serve رد نمی‌شود، پس حتی وقتی همه‌چیز درست است ممکن است گواهی اشتباه نشان بدهد. از یک دستگاه دیگر داخل Tailscale تست کن.
